# Social Media Addiction Analysis

## 📌 Project Overview
This project analyzes social media addiction among students using Python.  
It explores the relationship between social media usage, sleep habits, and mental health.  
The final report is documented in a Word file and the dataset is provided in CSV format.

---

## 📂 Files in this Repository
- `Social_Media_Addiction_Analysis.ipynb` → Python code & analysis steps  
- `Students Social Media Addiction.csv` → Dataset used for analysis  
- `Social_Media_Addiction_Analysis.docx` → Full project report (Word format)  
- `README.md` → Project description (this file)

---

##⚙️ Tools & Libraries Used
- Python (Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Scipy)
- Jupyter Notebook
- Microsoft Word (for the report)

---

## 📊 Key Findings
- Students who spend more hours daily on social media have higher addiction scores.  
- Sleep hours are negatively correlated with addiction levels.  
- Mental health score plays a significant role in predicting addiction.  
- Random Forest classifier achieved ~80% accuracy in predicting addiction level.
